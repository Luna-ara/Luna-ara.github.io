# Gemini Portfolio Project Mandates

This document outlines the engineering standards and project goals for the Luna-ara.github.io portfolio.

## Core Standards
- **Clean Code:** Use semantic HTML tags. Keep CSS organized by sections.
- **Visual Integrity:** Maintain a clean, professional aesthetic with responsive design.
- **Performance:** Optimize images and use lightweight scripts.
- **Verification:** Always verify changes by checking the layout in different screen sizes.

## Project Goals
- [ ] Implement a real Resume download link.
- [ ] Add at least two more projects to the "Featured Projects" section.
- [ ] Refine the "About Me" section with more specific achievements.
- [ ] Ensure all skill icons are correctly styled and interactive.

## Conventions
- Use CSS variables for colors and transitions.
- Prefer vanilla JavaScript for interactive elements.
- Keep assets organized in the `CSS/Img` folder.
